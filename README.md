# Descriptive Reality

**Where words become worlds.**

Descriptive Reality is a platform concept that connects readers, authors, and manga/manhwa artists. Authors share scenes from their stories, artists illustrate them, and readers discover both — bridging text-based fiction with visual storytelling.

This repo contains a front-end prototype built for [diploma / course name] — a static demo of the landing page, book browsing, and the "text to visual" concept.

## What's here
- `index.html` — main page structure
- `style.css` — styling
- `script.js` — interactivity (search, filters, modal, etc.)

## Status
Prototype / work in progress.
